
## RESUMO

Criei o sistema para automatizar o processo de desdobramento dos encartes, que antes era feito praticamente todo de forma manual. A partir da planilha enviada pelo Comercial, o sistema interpreta e organiza os dados dos produtos e utiliza essas informações para gerar os Preçários, Telas, Cards e Stories.

A ideia surgiu depois de eu trabalhar diretamente nesse processo e perceber o quanto ele era repetitivo, demorado e sujeito a erros de copiar e colar. O objetivo foi aproveitar uma informação que já existia de forma estruturada na planilha e fazer com que o sistema executasse a parte operacional, deixando para o usuário principalmente a revisão, os ajustes e a validação final.

Além da geração dos materiais, o sistema permite trabalhar separadamente com RS e MS, inserir e tratar imagens dos produtos, salvar o andamento do trabalho e gerar os arquivos finais em PDF, PNG e ZIP. Ao longo do desenvolvimento, a solução também foi evoluindo para lidar melhor com questões como imagens pesadas, geração de muitas peças, persistência dos dados e uso simultâneo por mais de um usuário.
