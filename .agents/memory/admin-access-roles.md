---
name: Acesso administrativo
description: Decisão de permissões para os perfis Operador e Administrador.
---

Operador e Administrador usam a mesma área de trabalho e podem selecionar, visualizar e editar tanto o encarte RS quanto o MS; o perfil administrativo existe para dar uma entrada separada e rastreável, não para restringir as ferramentas existentes do operador.

**Why:** A solicitação definiu que o administrador deve poder acompanhar e corrigir o trabalho junto ao operador, sem alterar o fluxo já usado nas etapas de montagem.

**How to apply:** Novas funcionalidades de montagem devem permanecer disponíveis para os dois perfis. Só introduza uma regra de permissão nova se ela for solicitada explicitamente.
